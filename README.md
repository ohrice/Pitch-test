# JG 音樂平台 - 音準測試系統

這是一個基於音準測試技術的音樂練唱平台。用戶可以上傳 MIDI 主旋律和伴奏檔案，系統會自動建立歌曲庫，然後進行即時音準測試。

## 📁 檔案結構

```
G:\JG\
├── index.html              # 主頁面（歌曲列表 + 測試介面）
├── upload.html             # 上傳歌曲頁面
├── app.js                  # 應用程式邏輯（歌曲管理、頁面切換）
├── db.js                   # IndexedDB 資料庫管理模組
├── pitch-test-engine.js    # 音準測試引擎（從 Pitch Test 複製）
└── README.md               # 說明文件
```

## 🎵 使用流程

### 1. 上傳歌曲

1. 開啟 `index.html`
2. 點擊「新增歌曲」卡片
3. 填寫歌曲資訊：
   - 歌曲名稱（必填）
   - 歌手名稱（必填）
   - 難度：簡單/中等/困難（必填）
   - 歌曲描述（選填）
4. 上傳檔案：
   - MIDI 主旋律檔案（必填）
   - 伴奏音檔（必填）
5. 點擊「儲存歌曲」

**檔案要求：**
- **MIDI 檔案**：.mid 或 .midi 格式，僅包含主旋律
- **伴奏音檔**：支援 MP3, WAV, M4A, AAC, OGG, WebM（建議每首 < 10MB，最大可達 50MB）

### 2. 選擇歌曲練唱

1. 在歌曲列表中點擊任一歌曲卡片
2. 系統自動載入 MIDI 和伴奏
3. 點擊「開始測試」開始練唱
4. 系統會即時顯示音準、音量和得分

### 3. 管理歌曲

- **搜尋**：使用上方搜尋欄搜尋歌曲或歌手
- **刪除**：點擊歌曲卡片右下角的 🗑️ 按鈕
- **返回**：在測試頁面點擊「返回歌曲列表」按鈕

## 💾 資料儲存

歌曲資料儲存在瀏覽器的 **IndexedDB** 中：

- ✅ 無需伺服器，完全本地運作
- ✅ 資料持久化，關閉瀏覽器後仍保留
- ✅ 隱私安全，資料不會上傳到網路
- ✅ **大容量**：可儲存數百 MB 甚至 GB 的資料（取決於瀏覽器）
- ✅ **支援大檔案**：單檔可達 50MB，適合高品質伴奏
- ⚠️ **注意**：清除瀏覽器資料會刪除所有歌曲

## 🚀 快速開始

### 方法 1：直接開啟（簡單）

直接用瀏覽器開啟 `G:\JG\index.html`

### 方法 2：使用本地伺服器（推薦）

為了避免 CORS 問題，建議使用本地伺服器：

#### Python 伺服器
```bash
cd "G:\JG"
python -m http.server 8000
# 瀏覽器開啟：http://localhost:8000
```

#### Node.js 伺服器
```bash
npm install -g http-server
cd "G:\JG"
http-server -p 8000
# 瀏覽器開啟：http://localhost:8000
```

#### VS Code Live Server
1. 安裝 VS Code 擴充套件：Live Server
2. 在 VS Code 中開啟 `G:\JG` 資料夾
3. 右鍵 `index.html` → "Open with Live Server"

## 📝 常見問題

### Q: 為什麼上傳後找不到歌曲？

A: 請確認：
1. 檔案大小是否過大（單檔建議 < 50MB）
2. 瀏覽器儲存空間是否足夠
3. 沒有清除瀏覽器資料
4. 使用支援 IndexedDB 的現代瀏覽器（Chrome, Firefox, Safari, Edge）

### Q: 可以儲存多少首歌曲？

A: 使用 IndexedDB 後，容量大幅提升：
- **一般瀏覽器**：可儲存數百 MB 到數 GB 的資料
- **Chrome/Edge**：通常可用磁碟空間的 60%（可達數 GB）
- **Firefox**：通常可用磁碟空間的 50%
- **Safari**：約 1GB（會提示用戶授權更多空間）
- **實際歌曲數**：如果每首歌約 5-10MB，可輕鬆儲存 60+ 首歌曲

### Q: 如何查看已使用的儲存空間？

A: 開啟瀏覽器控制台（F12），系統會自動顯示儲存空間使用情況

### Q: 如何備份歌曲資料？

A: 建議保留原始 MIDI 和伴奏檔案作為備份。IndexedDB 資料會在清除瀏覽器資料時被刪除。

### Q: 刪除歌曲後可以復原嗎？

A: 刪除後無法復原，請謹慎操作。建議保留原始檔案。

### Q: iPad Safari 需要先測試麥克風嗎？

A: 不需要！系統已經優化，點擊「開始測試」時會自動初始化麥克風。

## 🐛 故障排除

### 問題：無法載入歌曲

**解決方案**：
1. 檢查瀏覽器控制台是否有錯誤訊息
2. 清除瀏覽器快取後重試
3. 嘗試使用不同瀏覽器

### 問題：麥克風無法使用

**解決方案**：
1. 確認已授予麥克風權限
2. 如果使用 HTTPS 或 localhost 以外的網址，瀏覽器可能會阻擋
3. 點擊「測試麥克風」按鈕確認麥克風正常

### 問題：音準檢測不準確

**解決方案**：
1. 確保麥克風音量足夠（觀察音量條）
2. 減少背景噪音
3. 嘗試調整與麥克風的距離
